# Daily Routine (5.5 hours)

Do the blocks in this order. The order matters: memory work first while fresh, output work last.

| Block | Time | What | How |
|---|---|---|---|
| 1. Anki review | 45 min | All due kanji and vocab cards | Never skip. If you miss a day, the backlog doubles. Say every reading aloud. |
| 2. New kanji | 40 min | The day's kanji set (10–12 kanji) | For each: write 5 times, say on/kun readings, write both example words, add Anki card. |
| 3. New vocabulary | 45 min | The day's vocab range (35–45 words) | Read the example sentence aloud, cover the meaning and recall, add Anki cards (front: word in kanji; back: reading + meaning). |
| 4. Grammar | 60 min | The day's 3–5 grammar points | Read explanation, hand-copy the 3 examples, write 2 original sentences per point. Keep a grammar notebook. |
| 5. Reading | 45 min | Assigned passage, or reread previous passages | Weeks 1–5: kana/vocab reading. From week 6: one passage per 2 days, timed. Underline every grammar point you recognise. |
| 6. Listening | 45 min | Assigned source | 15 min shadowing (repeat aloud with the audio), 30 min extensive listening. From week 11: NHK Easy daily. |
| 7. Output | 30 min | Write or speak | Write a 5-sentence diary in Japanese using today's grammar, or record yourself summarising the reading passage. |

## Weekly

- **Saturday**: weekly self-test (see schedule), then 1 hour of free reading or Japanese TV with Japanese subtitles.
- **Sunday**: Anki only (1 hour). Rest otherwise.

## Rules that decide whether you pass

1. Anki every day, including travel days and sick days. Even 20 minutes.
2. Read everything aloud. Reading speed on the N2 is the main reason people run out of time.
3. Never learn a kanji without a word that contains it. Never learn a word without a sentence.
4. Listening daily from week 4. Listening is where self-learners fail the N2.
5. Log your daily hours in the progress tracker. If the weekly total drops below 30 hours, the schedule slips; add the shortfall to the next week.
