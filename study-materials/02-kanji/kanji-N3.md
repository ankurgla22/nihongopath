# JLPT N3 Kanji — Complete List (369 kanji, 31 daily sets of 12; Day 31 has 9)

Scope: the standard N3 kanji set (kanji beyond N5/N4). Learn one "Day" block per day; on Day 32 onward, cycle back and review with the example words covered.

How to use each row:
- **On-yomi** (katakana) = Sino-Japanese readings, used mostly in compounds.
- **Kun-yomi** (hiragana) = native readings; "—" means no common kun reading in everyday use.
- Learn the **two example words** as your minimum vocabulary anchor for the kanji.
