# JLPT N4 Vocabulary — 900 Words

Core vocabulary for the JLPT N4 level, organized by theme. These 900 words go beyond the N5 list (`vocab-N5.md`) and do not repeat it. Each entry gives the word (in kanji where it is normally written that way), the hiragana reading, part of speech, meaning, and a short example sentence using N4 grammar or below.

**Part of speech key:** n = noun, v = verb (vt = transitive, vi = intransitive), v-suru = する-verb noun, い-adj = い-adjective, な-adj = な-adjective, adv = adverb, conj = conjunction, exp = expression, pron = pronoun, ctr = counter, prt = prefix/suffix/particle
