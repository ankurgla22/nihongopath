# JLPT N5 Vocabulary — 700 Words

Complete core vocabulary for the JLPT N5 level, organized by theme. Each entry gives the word (in kanji where it is normally written that way), the hiragana reading, part of speech, meaning, and a short example sentence using only N5 grammar.

**Part of speech key:** n = noun, v = verb, い-adj = い-adjective, な-adj = な-adjective, adv = adverb, exp = expression, pron = pronoun, ctr = counter, conj = conjunction, prt = prefix/suffix/determiner, q = question word
