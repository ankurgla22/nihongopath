# JLPT N2 読解 練習パッセージ集

## 時間の目安（Time Targets）

| 種類 | 文字数の目安 | 目標時間 | 問題数 |
|---|---|---|---|
| 短文 | 約200字 | 3分 | 3問 |
| 中文 | 約500字 | 8分 | 4問 |
| 長文 | 約900字 | 12分 | 5問 |
| 統合理解 | A・B 各約300字 | 10分 | 3問 |
| 情報検索 | 表・案内 | 5分 | 2問 |

**使い方**
1. タイマーをセットし、目標時間内に本文を読んで問題に答える。
2. 答え合わせをしてから、語彙リストで知らなかった言葉を確認する。
3. 解答・解説を読み、なぜ正解なのか・なぜ誤答が違うのかを自分の言葉で説明できるようにする。
4. 翌日にもう一度本文だけを読み、時間が半分になるまで繰り返す。

## 短文 #1 — 納期変更のお願い（ビジネスメール）

株式会社ミナト 営業部 田中様

いつもお世話になっております。大和印刷の佐藤です。

先日ご依頼いただきましたパンフレットの件でご連絡いたしました。誠に申し訳ございませんが、用紙の入荷が遅れており、当初お約束した20日の納品が難しい状況です。つきましては、納期を25日に変更させていただけないでしょうか。

なお、どうしても20日にご入用の場合は、代わりの用紙で対応することも可能です。その場合、色味が若干異なる可能性がございますので、あらかじめご了承ください。

お手数をおかけしますが、ご検討のうえ、明日中にご返答いただけますと幸いです。

大和印刷 佐藤

### 問題

**問1** 佐藤がこのメールを書いた主な目的は何か。
1. パンフレットの注文を断るため
2. 納品の日を遅らせてほしいと頼むため
3. 用紙の色を変えてほしいと頼むため
4. 20日に納品できることを伝えるため

**問2** 20日に納品してもらう場合、どうなるか。
1. 料金が高くなる
2. 印刷ができなくなる
3. 色が少し違う可能性がある
4. 数量が減る

**問3** 佐藤は田中に何をしてほしいと言っているか。
1. 明日中に返事をする
2. 用紙を送る
3. 25日に来社する
4. 注文を取り消す

### 語彙

| 語 | 読み | 意味 |
|---|---|---|
| 納期 | のうき | delivery deadline |
| 納品 | のうひん | delivery of goods |
| 入荷 | にゅうか | arrival of stock |
| 当初 | とうしょ | originally, at first |
| つきましては | — | therefore (formal) |
| ご入用 | ごいりよう | needed (honorific) |
| 色味 | いろみ | color tone |
| 若干 | じゃっかん | slightly, somewhat |
| あらかじめ | — | in advance |
| ご了承 | ごりょうしょう | understanding, acknowledgment |
| お手数 | おてすう | trouble, bother |
| 幸いです | さいわいです | I would appreciate it |

### 解答・解説

- **問1: 2** — 「納期を25日に変更させていただけないでしょうか」が中心の依頼。選択肢1は誤り。注文を断ってはおらず、代替案まで示している。
- **問2: 3** — 「代わりの用紙で対応」→「色味が若干異なる可能性」と明記されている。選択肢1の料金については本文に一切触れられていない。
- **問3: 1** — 「明日中にご返答いただけますと幸いです」。選択肢3の来社は求めていない。

## 短文 #2 — 駐輪場利用に関するお知らせ

入居者の皆様へ

　4月1日より、マンション敷地内の駐輪場の利用方法が変わります。

　これまで駐輪場は先着順で自由に利用できましたが、放置自転車が増え、本来利用すべき方が停められないという苦情が多く寄せられています。そこで今後は、管理事務所で登録した自転車のみ駐輪できるようにいたします。登録された自転車には番号入りのシールを配布しますので、必ず目立つ位置に貼ってください。

　3月31日までに登録のない自転車は、4月15日以降、放置自転車とみなして撤去いたします。撤去後の保管期間は1か月とし、期間を過ぎたものは処分いたしますので、ご注意ください。

管理組合

### 問題

**問1** 利用方法を変える理由は何か。
1. 駐輪場を広くするため
2. 自転車を停められない人がいるため
3. シールの売り上げを増やすため
4. 駐輪場を廃止するため

**問2** 4月以降、駐輪場を使いたい人はどうしなければならないか。
1. 毎月料金を払う
2. 先着順で場所を取る
3. 管理事務所で登録してシールを貼る
4. 自転車を1か月以内に処分する

**問3** 登録していない自転車はどうなるか。
1. 4月1日にすぐ処分される
2. 4月15日以降に撤去され、1か月保管される
3. 3月31日に撤去される
4. 番号入りのシールが貼られる

### 語彙

| 語 | 読み | 意味 |
|---|---|---|
| 入居者 | にゅうきょしゃ | resident, tenant |
| 敷地 | しきち | premises, site |
| 駐輪場 | ちゅうりんじょう | bicycle parking |
| 先着順 | せんちゃくじゅん | first-come, first-served |
| 放置 | ほうち | leaving unattended |
| 本来 | ほんらい | originally, properly |
| 苦情 | くじょう | complaint |
| 寄せる | よせる | to send in (complaints) |
| 配布 | はいふ | distribution |
| みなす | — | to regard as |
| 撤去 | てっきょ | removal |
| 処分 | しょぶん | disposal |

### 解答・解説

- **問1: 2** — 「本来利用すべき方が停められないという苦情」が直接の理由。選択肢1の「広くする」は本文にない。
- **問2: 3** — 登録制になり、シールを貼ることが条件。選択肢2の「先着順」は「これまで」の方法で、今後は違う。
- **問3: 2** — 「4月15日以降…撤去」「保管期間は1か月」。選択肢1は時期も内容も誤り。すぐ処分されるのではなく、保管期間がある。

## 短文 #3 — 「効率」という言葉（意見文）

　最近、「効率よく」という言葉をよく耳にする。仕事も勉強も、短い時間で最大の成果を出すのがよいとされ、無駄を省くことが正義のように語られる。

　しかし、私はこの風潮に少し違和感を覚える。というのも、後になって役に立った経験の多くは、当時「無駄だ」と思っていたものだからだ。目的もなく読んだ本、遠回りして歩いた道、答えの出ない議論。それらが何年も経ってから思わぬ形でつながることがある。

　効率を追い求めること自体は悪くない。ただ、何が無駄かは、その時点では判断できないということを忘れてはならないと思う。

### 問題

**問1** 筆者が「違和感を覚える」のはなぜか。
1. 効率という言葉の意味が分からないから
2. 無駄だと思ったことが後で役に立った経験があるから
3. 効率を求めると成果が出ないから
4. 遠回りするのが好きだから

**問2** 筆者の考えに最も近いものはどれか。
1. 効率を追い求めるべきではない
2. 無駄なことは全部やめたほうがよい
3. 何が無駄かはすぐには分からない
4. 本は目的を持って読むべきだ

**問3** 「それら」が指すものは何か。
1. 効率のよい仕事の方法
2. 短い時間で出した成果
3. 一見無駄に見える経験
4. 最近よく聞く言葉

### 語彙

| 語 | 読み | 意味 |
|---|---|---|
| 効率 | こうりつ | efficiency |
| 耳にする | みみにする | to hear (of) |
| 成果 | せいか | result, achievement |
| 省く | はぶく | to omit, cut out |
| 正義 | せいぎ | justice, righteousness |
| 風潮 | ふうちょう | trend, tendency |
| 違和感 | いわかん | sense of discomfort |
| というのも | — | that is because |
| 遠回り | とおまわり | detour |
| 議論 | ぎろん | discussion, debate |
| 思わぬ | おもわぬ | unexpected |
| 追い求める | おいもとめる | to pursue |

### 解答・解説

- **問1: 2** — 「というのも」以下で理由を説明。「後になって役に立った経験の多くは、当時『無駄だ』と思っていたもの」。選択肢3は本文の主張と異なる。筆者は効率が成果を妨げるとは言っていない。
- **問2: 3** — 最終段落「何が無駄かは、その時点では判断できない」。選択肢1は言いすぎ。筆者は「効率を追い求めること自体は悪くない」と述べている。
- **問3: 3** — 直前の「目的もなく読んだ本、遠回りして歩いた道、答えの出ない議論」を指す。

## 短文 #4 — 給水設備工事に伴う断水のお知らせ

入居者各位

このたび、当マンションでは給水設備の老朽化に伴い、下記のとおり配管の交換工事を実施いたします。工事中は建物全体で断水となりますので、あらかじめ飲料水や生活用水の確保をお願いいたします。

日時：10月8日（火）午前9時〜午後3時（予定）
※天候や作業の進み具合により、終了時刻が前後する場合があります。

なお、工事終了直後は水道水が一時的に濁ることがあります。その際は、しばらく水を流してからご使用ください。また、当日はエレベーターも点検のため午前中のみ停止いたします。ご不便をおかけしますが、ご協力のほどよろしくお願い申し上げます。

みどり台マンション管理組合

### 問題

**問1** このお知らせの主な目的は何か。
1. 入居者に水道料金の値上げを知らせること
2. 工事の日に水が使えなくなることを知らせること
3. 入居者に工事への参加を求めること
4. エレベーターの故障を報告すること

**問2** 工事の終了時刻について、正しいものはどれか。
1. 必ず午後3時に終わる
2. 天候に関係なく午後3時より早く終わる
3. 状況によって午後3時より遅くなることもある
4. 午前中に終わる予定である

**問3** 工事が終わった直後、入居者はどうすればよいか。
1. 水が濁っていたら管理組合に連絡する
2. 水が濁っていたらしばらく流してから使う
3. 翌日まで水を使わない
4. エレベーターで飲料水を運ぶ

### 語彙

| 語 | 読み | 意味 |
|---|---|---|
| 各位 | かくい | everyone (formal address) |
| 給水 | きゅうすい | water supply |
| 老朽化 | ろうきゅうか | deterioration with age |
| 伴う | ともなう | to accompany, be associated with |
| 配管 | はいかん | piping, plumbing |
| 断水 | だんすい | water outage |
| 確保 | かくほ | securing, ensuring |
| 前後する | ぜんごする | to vary slightly (in time) |
| 濁る | にごる | to become cloudy, murky |
| 点検 | てんけん | inspection |
| 不便 | ふべん | inconvenience |
| 管理組合 | かんりくみあい | building management association |

### 解答・解説

- **問1: 2** — 「工事中は建物全体で断水となります」が中心の情報で、そのために水の確保を求めている。選択肢3は誤り。入居者に求めているのは「協力」であって、工事への参加ではない。

- **問3: 2** — 「しばらく水を流してからご使用ください」と明記。選択肢1の連絡は求められていない。

## 短文 #5 — 「読書離れ」について（意見文）

若者の読書離れが問題だと言われて久しい。確かに、電車の中で本を開いている人は減った。しかし、私はこの現象を単純に「若者が文字を読まなくなった」と捉えるのは正しくないと思う。

スマートフォンの画面を見ている人の多くは、ニュースやSNSの投稿、電子書籍など、何らかの文字を読んでいる。読む量そのものは、むしろ増えているのではないだろうか。変わったのは、読む量ではなく、読み方である。短い文章を大量に、断片的に読むようになったのだ。

問題があるとすれば、一冊の本を最初から最後まで読み通すような、長く集中して考える経験が減ったことだろう。それは「本を読め」と押しつけて解決するものではない。じっくり考えることの楽しさを、まず大人が示す必要がある。

### 問題

**問1** 筆者は「若者の読書離れ」という見方について、どう考えているか。
1. 若者が文字を読まなくなったのは深刻な問題だ
2. 若者の読む量が減ったという見方は正確ではない
3. 若者は本よりもニュースを読むべきだ
4. 電車の中で本を読む人が減ったのは当然だ

**問2** 筆者によると、変わったのは何か。
1. 読む文章の長さや読み方
2. 電子書籍の値段
3. 若者の集中力
4. 大人の読書量

**問3** 筆者が最も言いたいことは何か。
1. 若者に本を読むよう強く勧めるべきだ
2. 短い文章を読むのはやめたほうがいい
3. 大人が考えることの楽しさを示すことが大切だ
4. 読書離れは解決できない問題だ

### 語彙

| 語 | 読み | 意味 |
|---|---|---|
| 読書離れ | どくしょばなれ | drifting away from reading |
| 言われて久しい | いわれてひさしい | has long been said |
| 現象 | げんしょう | phenomenon |
| 捉える | とらえる | to grasp, interpret |
| 投稿 | とうこう | post (online) |
| 何らか | なんらか | some kind of |
| むしろ | — | rather, if anything |
| 断片的 | だんぺんてき | fragmentary |
| 読み通す | よみとおす | to read through to the end |
| 押しつける | おしつける | to force upon |
| じっくり | — | carefully, without hurry |
| 示す | しめす | to show, demonstrate |

### 解答・解説

- **問1: 2** — 「単純に『若者が文字を読まなくなった』と捉えるのは正しくない」「読む量そのものは、むしろ増えている」から。選択肢1は筆者が否定している見方そのもの。
- **問2: 1** — 「変わったのは、読む量ではなく、読み方である。短い文章を大量に、断片的に読むようになった」。選択肢3の集中力については、「経験が減った」とは述べているが、能力が変わったとは言っていない。
- **問3: 3** — 最終文「じっくり考えることの楽しさを、まず大人が示す必要がある」が結論。選択肢1は「押しつけて解決するものではない」と否定されている。

## 中文 #1 — 「ご近所」との距離（社会）

都市部に住む人の多くは、隣に誰が住んでいるのかを知らない。私自身、今のマンションに越してきて五年になるが、同じ階の住人と交わした言葉といえば、エレベーターでの「こんにちは」程度である。かつては「向こう三軒両隣」という言葉があり、近所同士で醤油を貸し借りするような付き合いが当たり前だった。それに比べると、現代の人間関係はずいぶん薄くなったと言われる。

しかし、私はこの変化を一方的に嘆くつもりはない。近所付き合いが濃かった時代には、その分、煩わしさも多かったはずだ。誰がいつ帰宅したか、どんな客が来たかまで知られてしまう生活を、今の私たちが望むとは思えない。都市の暮らしが人々に与えた最大の贈り物は、「放っておいてもらえる自由」だとさえ思う。

ただ、その自由には代償がある。災害が起きたとき、あるいは高齢になって体が思うように動かなくなったとき、頼れるのは結局、物理的に近くにいる人なのだ。遠くの親戚より近くの他人、という言葉は今も真実である。

では、どうすればよいのか。私は、昔のような濃い付き合いに戻る必要はないと考えている。必要なのは、「顔と名前が一致する」程度のゆるやかなつながりだ。年に一度の防災訓練に顔を出す、ごみ置き場で会ったときに一言交わす。それだけで、いざというときの心理的なハードルは大きく下がる。自由を手放さずに安心を得る方法は、意外と身近なところにあるのかもしれない。

### 問題

**問1** 筆者と同じ階の住人との関係はどのようなものか。
1. 醤油を貸し借りするような親しい関係
2. 挨拶をする程度の関係
3. 名前も顔も知らない関係

## 中文 #4 — 「もったいない」の行方（文化）

「もったいない」という日本語は、外国語に訳しにくい言葉の一つだと言われる。物を無駄にすることへの惜しさだけでなく、その物に対する敬意や、使い切れない自分への反省までが含まれているからだ。祖母は割れた茶碗を捨てる前に必ず「ありがとう」と言っていたが、あれはまさにこの感覚の表れだったのだろう。

ところが、現代の日本でこの言葉がどれほど生きているかというと、心もとない。食品ロスは年間数百万トンに達し、まだ着られる衣類が大量に廃棄されている。安く買って、飽きたら捨てる。そうした消費のあり方は、「もったいない」の精神とは正反対である。皮肉なことに、この言葉が海外で環境保護の合言葉として注目される一方で、本家の日本では影が薄くなりつつある。

なぜこうなったのか。理由の一つは、物が安くなりすぎたことだと思う。祖母の時代、茶碗は簡単に買い替えられるものではなかった。だからこそ、欠けても金継ぎをして使い続けた。物の値段が下がれば、それを大切にする理由も薄れる。「もったいない」は、道徳というより、物が貴重だった時代の生活の知恵だったのかもしれない。

とすれば、この言葉を復活させるには、単に「大切にしましょう」と呼びかけるだけでは足りない。物の背後にある時間や労力が見える仕組み、たとえば作り手の顔がわかる販売の方法や、修理して使い続けることを評価する文化が必要になる。言葉を守るとは、その言葉が生まれた条件を作り直すことなのだと思う。

## 長文 #1 — 「便利」の先にあるもの（意見文）

駅の改札を通るとき、私たちはもう切符を買わない。カードやスマートフォンをかざすだけで、料金は自動的に引き落とされる。コンビニのレジも、銀行の窓口も、役所の手続きさえも、次々と「人を介さない」形に置き換わっている。この流れを止めることはできないし、止める必要もないと私は思う。便利になることは、基本的には良いことだ。

だが、最近ある光景を見て、少し考え込んでしまった。スーパーのセルフレジの前で、高齢の男性が立ちすくんでいた。画面の指示がわからず、後ろには列ができている。店員は他のレジで手一杯だ。結局、男性はかごを置いたまま店を出ていった。彼にとって、その店は「便利」ではなく、ただ「入れない場所」になったのである。

便利さとは、誰にとっての便利さなのか。技術の設計者が想定しているのは、多くの場合、画面の操作に慣れ、視力や指の動きに問題のない人である。その想定から外れる人にとって、新しい仕組みは便利どころか、以前より高い壁になる。しかも厄介なことに、壁は静かに高くなっていく。切符売り場が一つ減り、有人窓口が一つ閉まる。その一つ一つは小さな変化だが、積み重なれば、ある日突然「自分にはもう使えない」という現実になって現れる。

これに対して、「使い方を学べばいい」という意見がある。確かに、講習会などの支援は重要だ。しかし、すべての人が学べるわけではないし、学ぶ速さより変わる速さのほうが速いという現実もある。ようやく覚えたころには、また新しい仕組みに変わっている。学ぶ努力を個人だけに求めるのは、公平とは言えないだろう。

私が求めたいのは、「便利さの速度を落とせ」ということではない。求めたいのは、新しい仕組みを導入するときに、そこから外れる人のための「もう一つの道」を残しておくことだ。有人の窓口を一つだけ残す。紙の申込書も受け付ける。電話でも手続きできるようにする。それらは効率の面ではコストに見えるかもしれない。しかし、その小さな非効率こそが、社会が誰かを置き去りにしないための、最低限の約束ではないだろうか。

技術は進歩し続ける。そして、私たちの誰もがいつか、変化の速さについていけない側に回る。そのときに「入れない場所」が増えている社会と、「もう一つの道」が残されている社会と、どちらに暮らしたいか。答えは、今の私たちの選択にかかっている。

## 長文 #2 — 「好きなことを仕事に」への疑問（意見文）

「好きなことを仕事にしよう」という言葉を、最近よく目にする。就職活動の本にも、起業を勧める広告にも、この言葉があふれている。好きなことなら努力が苦にならず、才能も伸びる。そう聞けば、確かにもっともに思える。

しかし、二十年近く働いてきた私は、この言葉に少し違和感を覚える。私自身、学生時代は写真が好きで、カメラマンになる道を真剣に考えた。結局、写真とは無関係の事務の仕事に就いたのだが、今になって思うのは、あのとき写真を仕事にしなくてよかった、ということだ。

理由は単純である。仕事にした瞬間、「好き」は「やらなければならないこと」に変わる。撮りたくない被写体を、気の乗らない日に、締め切りに追われながら撮る。それが仕事というものだ。好きだった写真が、いつの間にか義務になり、やがて嫌いになってしまう。そうした例を、私は周囲で何度も見てきた。趣味のままだったからこそ、私は今も週末にカメラを持って出かけることができる。

もう一つ、この言葉には見落とされがちな前提がある。それは、「好きなこと」がすでにはっきりしている人を想定している点だ。しかし実際には、若いうちに自分の好きなことを確信できる人はそれほど多くない。私の周りにも、「好きなことが見つからない」と悩んで、就職そのものをためらう若者がいる。「好きなことを仕事に」という言葉は、彼らを励ますどころか、かえって追い詰めているのではないか。

では、何を基準に仕事を選べばよいのか。私は、「好き」より「続けられるか」のほうが大切だと思う。派手な情熱がなくても、毎日やって苦にならないこと、やっているうちに少しずつ上手くなっていくこと。そういう仕事は、続けるうちに愛着が生まれる。私の事務の仕事も、最初は特に好きだったわけではない。しかし、書類を正確に整える作業が自分に向いていると気づき、十年目あたりから、これは自分の仕事だと思えるようになった。「好き」は出発点ではなく、到達点なのかもしれない。

誤解のないように言えば、好きなことを仕事にして幸せに働いている人を、私は否定しない。それがうまくいく人は確かにいる。ただ、それが唯一の正解であるかのように語られることには、反対したい。好きなことは、仕事にしなくても、人生を豊かにしてくれる。そして仕事は、好きでなくても、続けるうちに自分のものになる。若い人には、この二つを切り離して考える自由を持っていてほしいと思う。

### 問題

**問1** 筆者は「好きなことを仕事にしよう」という言葉に対してどう感じているか。
1. 完全に正しいと思っている
2. 少し疑問を感じている
3. 全く理解できないと思っている
4. 自分には関係ないと思っている

**問2** 筆者が写真を仕事にしなくてよかったと思う理由は何か。

2. 事務の仕事のほうが好きだったから
3. 仕事にすると好きなことが義務になり、嫌いになるおそれがあるから
4. 写真の才能がなかったから

**問3** 「見落とされがちな前提」とは何か。
1. 好きなことがすでにはっきりしている人を想定していること
2. 仕事は必ず苦しいものだということ
3. 若者は就職をためらうものだということ
4. 才能は努力で伸びるということ

**問4** 「『好き』は出発点ではなく、到達点なのかもしれない」とはどういう意味か。
1. 好きなことは若いうちに決めるべきだ
2. 好きという気持ちは仕事を続けるうちに生まれることがある
3. 好きな仕事に就くには長い時間がかかる
4. 仕事を好きになることは不可能だ

**問5** 筆者が若い人に望んでいることは何か。
1. 好きなことを必ず仕事にすること
2. 好きなことをあきらめて事務の仕事に就くこと
3. 好きなことと仕事を分けて考える自由を持つこと

### 解答・解説

- **問1: 2** — 「この言葉に少し違和感を覚える」と第二段落にある。選択肢3は言いすぎ。筆者は「確かにもっともに思える」と一定の理解を示している。
- **問2: 3** — 第三段落「仕事にした瞬間、『好き』は『やらなければならないこと』に変わる…やがて嫌いになってしまう」。選択肢2は誤り。事務の仕事は「最初は特に好きだったわけではない」と書かれている。

- **問4: 2** — 筆者自身の経験「続けるうちに愛着が生まれる」「十年目あたりから、これは自分の仕事だと思えるようになった」を一般化した表現。選択肢1は逆の考え方で、筆者が疑問を示している「好きなことを仕事に」の立場に近い。
- **問5: 3** — 最終文「この二つを切り離して考える自由を持っていてほしい」。選択肢2は誤り。筆者は「好きなことを仕事にして幸せに働いている人を、私は否定しない」と述べており、特定の職業を勧めてはいない。

## 統合理解 #1 — 在宅勤務は続けるべきか

**A**

在宅勤務を経験して三年になるが、私はこの働き方を今後も続けるべきだと考えている。最大の利点は、通勤時間がなくなったことだ。往復二時間を家族との時間や睡眠に充てられるようになり、生活の質は明らかに上がった。仕事の面でも、周囲に話しかけられることがないため、資料作成や分析のような集中を要する作業ははかどる。一部には「在宅だとさぼるのではないか」という声もあるが、成果で評価する仕組みさえ整っていれば、どこで働くかは本質的な問題ではない。むしろ、オフィスにいることが「働いている証拠」とされてきた古い考え方こそ、見直すべきではないだろうか。

**B**

在宅勤務には確かに利点があるが、私は週の大半はオフィスで働くほうがよいと考えている。理由は、仕事の質は個人の集中力だけで決まるものではないからだ。ちょっとした立ち話から新しい企画が生まれたり、隣の席の先輩の対応を見て若手が学んだりする。こうした偶然の学びは、画面越しの会議ではほとんど起こらない。実際、私の部署では在宅中心にしてから、新人の成長が目に見えて遅くなった。もちろん、通勤の負担が減るという利点は否定しない。だからこそ、週に一、二日の在宅を認めつつ、基本はオフィスという形が現実的だと思う。

### 問題

**問1** AとBに共通する認識はどれか。
1. 在宅勤務では社員がさぼりやすい
2. 通勤の負担が減ることは利点である
3. 新人の教育はオンラインで十分できる
4. 成果による評価は不可能である

**問2** Bが在宅勤務に慎重な主な理由は何か。

2. 会社の設備が家庭にはないから
3. 偶然の会話から生まれる学びや企画が減るから
4. 通勤時間が短いと生活のリズムが崩れるから

**問3** AとBの意見の違いを正しく説明しているものはどれか。
1. Aは在宅勤務を続けるべきだと考え、Bはオフィス中心に在宅を組み合わせるべきだと考えている
2. Aは在宅勤務に反対し、Bは賛成している
3. AもBも在宅勤務を完全にやめるべきだと考えている
4. Aは新人の教育を重視し、Bは個人の集中を重視している

## 統合理解 #2 — 子どもにスマートフォンを持たせる時期

**A**

小学生のうちからスマートフォンを持たせることに、私は賛成である。理由の一つは安全面だ。習い事や塾で帰りが遅くなる日、位置情報を確認できたり、すぐに連絡が取れたりすることは、親にとって大きな安心になる。もう一つは、早く持たせたほうが、正しい使い方を親の目の届く範囲で身につけられるという点だ。中学生になって突然持たせると、親の言うことを聞かない年頃に入っており、指導が難しくなる。使用時間の制限やフィルタリングなど、道具の側にも対策は用意されている。禁止するのではなく、使い方を教えるのが親の役割だと思う。

**B**

子どもにスマートフォンを持たせるのは、早くても中学生になってからでよいと私は考える。確かに連絡手段としての便利さはあるが、それだけなら通話と位置情報に機能を絞った子ども用の端末で十分だ。問題は、スマートフォンが単なる連絡手段ではなく、動画やゲーム、SNSへの入り口でもあることだ。小学生の段階では、自分で時間を管理する力がまだ育っていない。フィルタリングなどの対策も、実際には子どものほうが親より抜け道に詳しいことが多い。使い方を教えることは大切だが、その前に、画面から離れて遊んだり本を読んだりする習慣を先に作っておくべきだと思う。

### 問題

**問1** AとBの両方が認めていることは何か。
1. 小学生は自分で時間を管理できる
2. フィルタリングは完全に有効である
3. 連絡が取れることには利点がある

4. 動画やゲームがよりよく楽しめるから

1. Aは安全面を重視せず、Bは安全面を重視している
2. Aは早く持たせて使い方を教えるべきだと考え、Bは他の習慣を先に作るべきだと考えている
3. Aはフィルタリングに反対し、Bは賛成している
4. Aは中学生から持たせるべきだと考え、Bは小学生から持たせるべきだと考えている

### 問題

**問1** 会社員のリンさん（28歳）は、平日の昼間は仕事があり、夜か週末にしか通えない。子どもはいない。リンさんが申し込める講座はどれか。
1. はじめての水彩画
2. 実用ビジネス英会話
3. 親子で楽しむ料理教室
4. スマートフォン入門

**問2** 「はじめての水彩画」に申し込んだ人が、9月28日に都合が悪くなって受講をやめる場合、どうなるか。
1. 受講料と教材費の両方が返金される
2. 受講料の半額が返金される
3. 講座開始日の7日前までなので、受講料が全額返金される
4. 申込期間が過ぎているので、受講料は返金されない

### 解答・解説

- **問1: 2** — リンさんが通えるのは平日の夜か週末。水彩画（火曜午前）とスマートフォン入門（木曜午後、かつ60歳以上）は除外。料理教室は土曜だが「小学生と保護者」が対象なので、子どものいないリンさんは申し込めない。残る「実用ビジネス英会話」は水曜19時からで、18歳以上という条件も満たす。選択肢3は曜日だけを見ると可能に見えるが、対象の条件で外れる。
- **問2: 3** — 水彩画の開始日は10月7日。7日前は9月30日なので、9月28日の申し出は期限内であり、受講料は「全額返金」の対象になる。選択肢1は誤り。教材費は初回に徴収されるので、取り消しの場合はそもそも払っていない（返金の対象ではない）。選択肢4は誤り。返金の期限は「申込期間」ではなく「講座開始日の7日前」である。
