# 聴解スクリプト集 — Listening Practice Scripts (20 original JLPT-style dialogues)

> Companion file to `listening-guide.md`. All scripts are original and written in the register and format of the JLPT 聴解 section (N3–N2 level). They are **not** copies of official test items.

## How to use these scripts (read this first)

The scripts are written to be *heard*, not read. Reading them silently trains reading, not listening. Use a text-to-speech (TTS) engine so that you can practise exactly as in the exam: **listen first, answer, and only then open the script**.

### Option A — Microsoft Edge "Read Aloud" (recommended, free, natural voices)
1. Open this file in Edge (drag the `.md` file into a tab, or open it via a Markdown preview page).
2. Select the Japanese script text, right-click, choose **Read aloud selection** (or press `Ctrl+Shift+U`).
3. In the top bar choose **Voice options** and pick a Japanese voice such as *Microsoft Nanami Online (Natural)* or *Microsoft Keita Online (Natural)*.
4. Set speed to **1.0** the first time; the JLPT is read at normal conversational speed. Use 0.8 only for the first weeks, then return to 1.0 and eventually 1.2 for over-training.
5. Edge uses one voice for the whole selection. Read the dialogue once with a female voice and once with a male voice. This is good training in itself.

### Option B — Windows Narrator
1. Settings > Time & Language > Language & region > add **日本語** and install the speech pack.
2. Settings > Accessibility > Narrator > Voice > choose *Microsoft Nanami* / *Microsoft Ichiro* / *Microsoft Ayumi*.
3. Turn Narrator on (`Win+Ctrl+Enter`), place the cursor at the start of the script and use `Narrator key + Ctrl + R` (read from cursor).

### Option C — Google Translate voice
1. Go to translate.google.com, set the source language to Japanese, paste **one speaker's line at a time** (the voice is more natural with shorter text).
2. Click the speaker icon. Click a second time for a slower reading.
3. Best used for the 即時応答-style single utterances and for shadowing individual lines.

### Option D — Other free engines
- VOICEVOX (free desktop app with very natural voices; you can assign a different voice to each speaker).
- The "Read Aloud" browser extension for Chrome / Firefox.

### Practice procedure (per script)
1. **Cover the script.** Read only the *Setting* line and the *Question*. (In the real test the question is read before the dialogue in 課題理解 / ポイント理解, so this is authentic.)
2. Play the TTS once. Choose an answer.
3. Play again. Confirm or change the answer.
4. Only now open the script. Check the answer and explanation. Mark every word you did not catch.
5. **Shadow** the script line by line with TTS at 1.0 speed (see `listening-guide.md` for the shadowing method).
6. Come back to the same script 3 days later and try it at 1.2 speed without the script.

Keep a log: script number, first-try correct?, words missed. Scripts you fail twice go into your Anki deck as sentence cards.

### Question types in this file
| # | Type | What is tested |
|---|------|----------------|
| 1–8 | 課題理解 (task comprehension) | What must the person do **next**? Watch for changes of plan, cancellations, "やっぱり", "その前に". |
| 9–14 | ポイント理解 (point comprehension) | One specific point: the **reason**, the **time**, the **place**, the **opinion**. Ignore distractors. |
| 15–17 | 概要理解 (summary comprehension) | The **main idea** of a monologue. The question is only heard *after* the talk. |
| 18–20 | 統合理解 (integrated comprehension) | Longer talk with several pieces of information; compare and combine. |

## 課題理解 (Task comprehension) — Scripts #1–8

### Script #1 — コピー機の前で
**Setting:** 会社で、男の人と女の人が話しています。女の人はこのあとまず何をしますか。

```
男：田中さん、ちょっといい？三時の会議の資料、もうコピーした？
女：はい、今から十部コピーしようと思ってたところです。
男：あ、ちょっと待って。さっき部長から連絡があって、二ページ目の売上の数字が古いんだって。
女：えっ、そうなんですか。じゃあ、部長に新しい数字を聞いてきます。
男：いや、それは僕がもうもらってあるから、このメモの通りに直しておいて。直したら、コピーの前に一度僕に見せてくれる？
女：わかりました。あ、会議室の予約は大丈夫ですか。
男：うん、それはもうしてあるから。
女：じゃあ、すぐ取りかかります。
```

**Question:** 女の人はこのあとまず何をしますか。

1. 資料を十部コピーする
2. 部長に新しい数字を聞きに行く
3. 資料の数字を直す
4. 会議室を予約する

**Answer:** 3

**Explanation:** 女の人は最初コピーするつもりだったが（選択肢1は元の予定）、数字が古いので直す必要がある。部長に聞く必要はない（男の人がもうもらっている、2は×）。会議室はもう予約済み（4は×）。「直したら、コピーの前に見せて」なので、まず数字を直す。

### Script #2 — 大学の事務室で
**Setting:** 大学の事務室で、学生と職員が話しています。学生はこのあと何をしなければなりませんか。

```
学生：すみません、奨学金の申し込みをしたいんですが。
職員：はい。申込書はもう書きましたか。
学生：はい、これです。あと、成績証明書も持ってきました。
職員：ええと……申込書は大丈夫ですね。成績証明書も……あ、これ、先学期のものですね。今学期のものが必要なんです。
学生：今学期のですか。それは、どこでもらえますか。
職員：一階の証明書発行機で出せますよ。学生証があればすぐです。
学生：わかりました。じゃあ、それを取ってきてから、またここに来ればいいですか。
職員：ええ。それから、指導教員の推薦状も要るんですが、それはお持ちですか。
学生：あ、先生には先週お願いしてあって、明日もらえることになっています。
職員：そうですか。じゃあ、それは明日でいいですよ。今日は証明書だけお願いします。
```

**Question:** 学生はこのあと何をしなければなりませんか。

1. 申込書を書き直す
2. 今学期の成績証明書を取りに行く
3. 先生に推薦状を頼む
4. 明日もう一度事務室に来る

**Answer:** 2

**Explanation:** 申込書はOK（1×）。成績証明書は先学期のものだったので、今学期のものを一階で発行する必要がある（2○）。推薦状はすでに頼んであり明日もらえる（3×）。明日来るのは推薦状のためで、「今日は証明書だけ」と言われているので、今すぐの行動は2。

### Script #3 — 引っ越しの準備
**Setting:** 家で、夫と妻が引っ越しの準備について話しています。夫はこのあとまず何をしますか。

```
妻：ねえ、引っ越し、来週の土曜日でしょう。段ボール、全然足りないんだけど。
夫：じゃあ、ホームセンターで買ってこようか。
妻：うーん、買うと高いから、引っ越し業者に電話して、追加でもらえるか聞いてみて。無料でくれるって言ってたから。
夫：ああ、そうだったね。じゃあ電話するよ。あと、粗大ごみの申し込み、した？
妻：あっ、忘れてた。古いソファ、出すんだよね。市役所のホームページから申し込めるんだけど、私、今から仕事だから……。
夫：わかった、それも僕がやっとく。
妻：ありがとう。でも、粗大ごみは収集日が決まってるから、先に日にちを調べてからね。ソファは引っ越しの前の日までに出さないと。
夫：うん。じゃあ、まず業者に電話して、そのあとホームページを見るよ。
```

**Question:** 夫はこのあとまず何をしますか。

1. ホームセンターで段ボールを買う
2. 引っ越し業者に電話する
3. 市役所のホームページで粗大ごみを申し込む
4. 古いソファを外に出す

**Answer:** 2

**Explanation:** 段ボールは買わずに業者からもらう（1×、2○）。粗大ごみの申し込みも夫がするが、夫自身が「まず業者に電話して、そのあとホームページを見る」と順番を言っている（3は二番目）。ソファを出すのはずっと後（4×）。

### Script #4 — 病院の受付
**Setting:** 病院の受付で、女の人と受付の人が話しています。女の人はこのあとどうしますか。

```
女：すみません、九時半に予約している山口ですが。
受付：山口様ですね。診察券と保険証をお願いします。
女：はい。あ、保険証、先月新しくなったんですけど、まだ古いのしか持っていなくて……。
受付：そうですか。古い保険証ですと、今日は一度全額をお支払いいただくことになります。新しい保険証を今月中にお持ちいただければ、差額はお返しします。
女：全額ですか……。新しいのは家にあるんです。家、ここから十分くらいなんですけど、取りに帰ったら間に合いますか。
受付：うーん、今日は混んでいますので、予約の時間に遅れると、順番がかなり後になってしまいますね。
女：そうですか。じゃあ、今日はこのまま受けて、今週中にまた来ます。
受付：かしこまりました。では、こちらの番号札を持って、二階の待合室でお待ちください。
```

**Question:** 女の人はこのあとどうしますか。

1. 家に新しい保険証を取りに帰る
2. 全額を払って診察を受ける
3. 予約を来週に変更する
4. 一階の待合室で待つ

**Answer:** 2

**Explanation:** 取りに帰ると順番が遅くなるので、女の人は「このまま受けて」と決めた（1×、2○）。予約の変更は話していない（3×）。待合室は「二階」（4×）。差額は後で返してもらえる。

### Script #5 — 部活の連絡
**Setting:** 学校で、先生と学生が話しています。学生は明日、何時に、どこに行きますか。

```
先生：明日の試合だけど、集合は八時に学校の正門だったよね。
学生：はい、そのつもりでした。
先生：それがね、バスの都合で三十分早くなったんだ。それから、場所も正門じゃなくて体育館の前にしてほしいって、事務の人に言われて。
学生：えっ、七時半に体育館の前ですか。
先生：そう。荷物が多いから、バスを体育館の横に止めることになったんだよ。みんなに連絡しておいてくれる？
学生：わかりました。すぐグループに送ります。
先生：ああ、あと、雨だったら試合は中止で、その場合は朝六時までに連絡するから。
学生：はい。
```

**Question:** 学生は明日、何時に、どこに行きますか。

1. 八時に正門
2. 七時半に正門
3. 八時に体育館の前
4. 七時半に体育館の前

**Answer:** 4

**Explanation:** 元の予定（八時・正門）から、「三十分早く」＝七時半、「体育館の前」に両方変更された。学生自身が「七時半に体育館の前ですか」と確認して先生が「そう」と答えている。

### Script #6 — レストランの注文
**Setting:** レストランで、店員と客が話しています。客は何を注文しますか。

```
店員：ご注文はお決まりですか。
客：ええと、このハンバーグセットをお願いします。
店員：かしこまりました。セットのライスとパンはどちらになさいますか。
客：ライスで。
店員：はい。あと、飲み物はコーヒー、紅茶、オレンジジュースからお選びいただけます。
客：じゃあ、紅茶を。……あ、すみません、このセット、サラダは付いてますか。
店員：申し訳ございません、サラダは別料金で、プラス二百円になります。
客：うーん、じゃあ、サラダはいいです。あ、でも、飲み物、食後に持ってきてもらえますか。
店員：かしこまりました。紅茶を食後にですね。
客：あ、ごめんなさい、やっぱりコーヒーにします。食後にお願いします。
店員：かしこまりました。
```

**Question:** 客は何を注文しますか。

1. ハンバーグセット、ライス、紅茶
2. ハンバーグセット、ライス、コーヒー
3. ハンバーグセット、パン、コーヒー、サラダ
4. ハンバーグセット、ライス、コーヒー、サラダ

**Answer:** 2

**Explanation:** ライスを選び（パンではない）、飲み物は最初「紅茶」だったが「やっぱりコーヒー」に変更。サラダは有料と聞いて「いいです」（＝要らない）。「やっぱり」「〜はいいです」は聴解の定番の言い換え。

### Script #7 — アルバイトのシフト
**Setting:** アルバイト先で、店長と女の学生が話しています。女の学生はいつ働きますか。

```
店長：佐藤さん、来週のシフトのことなんだけど、水曜日、入れる？
学生：水曜日ですか。すみません、水曜は午後からゼミがあって……。午前中なら大丈夫です。
店長：午前か。うーん、足りないのは夕方なんだよね。じゃあ木曜の夕方は？
学生：木曜は、六時からなら行けます。
店長：六時から九時までで頼める？
学生：はい、大丈夫です。
店長：助かるよ。あと、土曜日も頼みたかったんだけど、鈴木くんが入れるって言ってたから、そっちはいいや。
学生：わかりました。じゃあ、木曜だけですね。
店長：うん、よろしくね。
```

**Question:** 女の学生はいつ働きますか。

1. 水曜日の午前
2. 水曜日の夕方
3. 木曜日の夕方
4. 木曜日と土曜日

**Answer:** 3

**Explanation:** 水曜の午前は学生ができるが、店長が必要なのは夕方なので採用されない（1×）。木曜六時から九時で決定（3○）。土曜は鈴木くんが入るので「そっちはいいや」＝不要（4×）。

### Script #8 — 図書館の本
**Setting:** 図書館で、男の人と図書館の職員が話しています。男の人はこのあとまず何をしますか。

```
男：すみません、この本を借りたいんですが、貸し出し中って書いてあって。
職員：少々お待ちください。……はい、今、ほかの方が借りていますね。返却予定は来週の月曜日です。予約なさいますか。
男：お願いします。
職員：では、こちらの用紙に利用者番号とお名前をお書きください。
男：あ、利用者カード、今日持ってきていないんです。番号、わからないんですけど……。
職員：そうですか。それでしたら、こちらのパソコンで、お名前と生年月日を入れると番号が調べられますよ。
男：わかりました。それをやってから、用紙に書けばいいですね。
職員：はい。本が返ってきたら、メールでお知らせします。メールアドレスも用紙にお願いします。
男：はい、ありがとうございます。
```

**Question:** 男の人はこのあとまず何をしますか。

1. 利用者カードを家に取りに帰る
2. パソコンで利用者番号を調べる
3. 用紙に名前と番号を書く
4. 来週の月曜日にもう一度来る

**Answer:** 2

**Explanation:** 番号がわからないので、まずパソコンで調べ（2○）、そのあと用紙に書く（3は二番目）。取りに帰るとは言っていない（1×）。本の返却は来週だが、来る必要はなくメールで知らせてくれる（4×）。

## ポイント理解 (Point comprehension) — Scripts #9–14

### Script #9 — 遅刻の理由
**Setting:** 会社で、女の人と男の人が話しています。男の人はどうして遅れましたか。

```
女：山田さん、遅かったですね。電車、止まってたんですか。
男：いえ、電車は普通に動いてました。
女：じゃあ、寝坊？
男：それが、家を出るときはいつも通りだったんですよ。でも、駅に着いたら、財布を忘れたことに気づいて。
女：ああ、それで取りに帰ったんですか。
男：いえ、取りに帰る時間はなかったので、そのまま来ようとしたんですけど、定期券も財布に入れてて。駅員さんに事情を話して、なんとか乗せてもらうのに時間がかかっちゃって。
女：大変でしたね。
男：ええ。お昼ご飯もどうしようかと……。
```

**Question:** 男の人はどうして遅れましたか。

1. 電車が止まっていたから
2. 寝坊したから
3. 財布を取りに家に帰ったから
4. 駅で駅員と話していたから

**Answer:** 4

**Explanation:** 電車は動いていた（1×）。家を出た時間は普通だった（2×）。取りに帰る時間はなかった（3×）。定期券がなく、駅員に事情を話すのに時間がかかったのが理由（4○）。「それが……」のあとに本当の理由が来る。

### Script #10 — 旅行の感想
**Setting:** 友達同士が旅行について話しています。女の人は旅行で何が一番よかったと言っていますか。

```
男：北海道、どうだった？
女：楽しかったよ。でも、思ったより寒くて、ちょっと大変だった。
男：温泉には入った？
女：うん、温泉もよかったんだけど、実は温泉はどこにでもあるでしょう。それより、海の幸がすごかった。朝市で食べたウニが、もう、今まで食べたのと全然違って。
男：へえ、いいなあ。景色は？
女：景色もきれいだったよ。雪の山とか。でも、寒くて長くは外にいられなかったから、やっぱり食べ物かな。
男：じゃあ、次は夏に行くといいね。
女：うん、そうする。
```

**Question:** 女の人は旅行で何が一番よかったと言っていますか。

1. 温泉
2. 食べ物
3. 景色
4. 気候

**Answer:** 2

**Explanation:** 温泉もよかったが「どこにでもある」、景色も「きれい」だが寒くて長く見られなかった。「それより」「やっぱり食べ物かな」で結論は食べ物（2○）。気候（寒さ）はマイナス点。

### Script #11 — セミナーの申し込み
**Setting:** 男の人がセミナーの案内を聞いています。申し込みはいつまでにしなければなりませんか。

```
女：本日は「はじめての投資セミナー」のご案内です。セミナーは来月十五日、土曜日の午後二時から四時まで、市民センターの三階で行います。参加は無料ですが、定員が三十名ですので、事前のお申し込みが必要です。お申し込みは、ホームページか電話で、来月八日までにお願いいたします。ただし、定員になり次第、締め切らせていただきますので、お早めにどうぞ。なお、当日は筆記用具をお持ちください。資料はこちらで用意いたします。
```

**Question:** 申し込みはいつまでにしなければなりませんか。

1. 来月八日まで
2. 来月十五日まで
3. 今月八日まで
4. 当日まで

**Answer:** 1

**Explanation:** セミナー当日は十五日だが、申し込みは「来月八日まで」。「定員になり次第締め切り」なので、実際にはもっと早く締め切る可能性がある。日付が二つ出てくるときは、どちらが「申し込み」でどちらが「開催」か区別する。

### Script #12 — 新しいスマートフォン
**Setting:** 電器店で、女の人と店員が話しています。女の人はどうしてこのスマートフォンを買うことにしましたか。

```
店員：こちらの新しいモデル、いかがですか。カメラの性能がかなり上がっていますよ。
女：カメラはあまり使わないんです。それより、電池はどのくらい持ちますか。今のは一日持たなくて。
店員：こちらは、普通にお使いいただければ二日は持ちます。
女：二日ですか。それはいいですね。値段は……ちょっと高いですね。
店員：今、古い機種をお持ちいただくと、一万円引きになるキャンペーンをやっています。
女：一万円引きでも、まだ高いなあ。……でも、毎日充電するのが本当に面倒だったから。うん、やっぱりこれにします。
店員：ありがとうございます。
```

**Question:** 女の人はどうしてこのスマートフォンを買うことにしましたか。

1. カメラの性能がいいから
2. 電池が長く持つから
3. 値段が安いから
4. 一万円引きになるから

**Answer:** 2

**Explanation:** カメラは「あまり使わない」（1×）。値段は「高い」「一万円引きでもまだ高い」（3×、4×）。決め手は「毎日充電するのが面倒だったから」＝電池が持つこと（2○）。

### Script #13 — 会議の時間
**Setting:** 会社で、男の人と女の人が話しています。会議は何時から始まりますか。

```
男：明日の会議、十時からだよね。
女：あ、それが、田中部長が午前中出張になって、午後に変わったんです。
男：午後？何時？
女：最初は一時って聞いたんですけど、一時はほかの部の会議で会議室が使えなくて。
男：じゃあ、二時？
女：二時半です。会議室が空くのが二時で、準備に三十分見ておきたいって。
男：わかった。じゃあ、二時半に会議室だね。
女：はい。資料は二時までに配っておきます。
```

**Question:** 会議は何時から始まりますか。

1. 十時
2. 一時
3. 二時
4. 二時半

**Answer:** 4

**Explanation:** 十時は午後に変更、一時は会議室が使えない、二時は会議室が空く時間で準備が必要、結論は二時半。時間が四つも出てくるが、最後に男の人が「二時半に会議室だね」と確認している。

### Script #14 — 先生の評価
**Setting:** 学生二人が授業について話しています。男の学生は新しい先生についてどう思っていますか。

```
女：新しい先生の授業、どう？私はちょっと速すぎると思うんだけど。
男：速いのは確かだね。でも、僕は前の先生より好きだな。
女：そう？どうして？
男：前の先生は教科書を読むだけだったでしょう。今の先生は、実際の例をたくさん出してくれるから、わかりやすいんだよ。
女：うーん、でも、宿題が多くない？
男：多いけど、あれをやると授業の内容が本当に頭に入るからさ。ただ、声が小さいのだけは何とかしてほしいな。後ろの席だと聞こえないときがある。
女：それは私も思う。
```

**Question:** 男の学生は新しい先生についてどう思っていますか。

1. 授業が速すぎてわかりにくい
2. 教科書を読むだけでつまらない
3. 説明がわかりやすいが声が小さい
4. 宿題が多すぎてよくない

**Answer:** 3

**Explanation:** 速いことは認めるが、それが問題とは言っていない（1×）。教科書を読むだけなのは「前の先生」（2×）。宿題は多いが「頭に入る」のでよい（4×）。「わかりやすい」＋「声が小さいのだけは何とかしてほしい」（3○）。「ただ、〜だけは」の後に唯一の不満が来る。

### Script #15 — ラジオの話
**Setting:** ラジオで、女の人が話しています。

```
女：みなさんは、朝ごはんを毎日食べていますか。最近の調査では、二十代の若い人の三人に一人が、朝ごはんを食べていないそうです。理由を聞くと、「時間がない」「食欲がない」という答えが多いんですね。でも、朝ごはんを抜くと、午前中、頭がぼんやりして、仕事や勉強の効率が下がることがわかっています。それに、お昼にお腹がすきすぎて食べすぎてしまい、かえって太りやすくなるという研究もあります。「ちゃんとした朝ごはん」でなくてもいいんです。バナナ一本、ヨーグルト一つでも、食べないよりずっといい。まずは、何か一つ口に入れることから始めてみませんか。
```

**Question:** 女の人は何について話していますか。

1. 若い人の朝ごはんの内容
2. 朝ごはんを食べないことの問題と、簡単な解決方法
3. ダイエットに効果的な食べ物
4. 朝ごはんを食べない人が増えた理由

**Answer:** 2

**Explanation:** 「食べない人が多い」から「食べないと効率が下がる、太りやすい」（問題）、そして「バナナ一本でもいいから食べよう」（解決）。全体の主題は2。理由（4）や内容（1）は部分的にしか出てこない。

### Script #16 — 会社の朝礼
**Setting:** 会社で、部長が社員に話しています。

```
部長：えー、みなさん、おはようございます。今日は一つお願いがあります。先月から、社内のメールが急に増えていますね。私のところにも、一日に百通以上来ます。確認したところ、そのうち半分近くが、「了解しました」「ありがとうございます」だけの返信でした。もちろん、お礼を言うのは大切です。ただ、それをメールで全員に送る必要があるかどうか、一度考えてみてください。隣の席なら口で言えばいいし、本当に必要な相手だけに送れば、みんなの時間が節約できます。メールを減らすこと自体が目的ではありません。大事な連絡が、たくさんのメールの中に埋もれてしまわないようにしたいんです。ご協力、お願いします。
```

**Question:** 部長が一番言いたいことは何ですか。

1. メールでお礼を言うのはよくない
2. 一日のメールの数を決めるべきだ
3. 必要のないメールを減らして、大事な連絡を見逃さないようにしてほしい
4. 隣の席の人には口で話すべきだ

**Answer:** 3

**Explanation:** お礼自体は「大切」（1×）。数を決めるとは言っていない（2×）。隣の席の話は一つの例（4は部分）。「メールを減らすこと自体が目的ではない」「大事な連絡が埋もれないように」が結論（3○）。

### Script #17 — 講演の一部
**Setting:** 男の人が、外国語の学習について話しています。

```
男：外国語を勉強していると、「毎日やらなければ」と思う人が多いんですね。もちろん、毎日やれれば理想です。でも、私が見てきた学習者の中で、途中でやめてしまう人の多くは、実は「毎日できなかった自分」に失望してやめてしまうんです。一日休んだ、三日休んだ、もうだめだ、と。これはもったいない。語学は、一日休んでも消えません。大事なのは、休んだあとに戻ってくることです。私は学習者によく言います。「三日休んでもいい。四日目に戻ってきなさい」と。完璧な学習者になる必要はないんです。長く続ける学習者になってください。
```

**Question:** 男の人が言いたいことは何ですか。

1. 外国語は毎日勉強しなければ上達しない
2. 休んでも、また続けることが大切だ
3. 三日以上休むと外国語を忘れてしまう
4. 完璧に勉強できる人だけが上達する

**Answer:** 2

**Explanation:** 毎日が「理想」だが必須ではない（1×）。「一日休んでも消えない」（3×）。「完璧な学習者になる必要はない」（4×）。「休んだあとに戻ってくること」「長く続ける学習者に」が主張（2○）。

### Script #18 — 三つのアルバイト
**Setting:** 学生二人が、アルバイトの求人を見ながら話しています。

```
女：ねえ、このアルバイト三つ、どれがいいと思う？
男：どれどれ。一つ目はコンビニ。時給は千百円で、家から歩いて五分。でも、深夜のシフトが多いって書いてある。
女：深夜はちょっと。授業に出られなくなるし。
男：二つ目は塾の先生。時給は千八百円で高いけど、週三日は必ず入らないといけないんだって。場所は駅の向こうで、自転車で二十分。
女：週三日かあ。ゼミが忙しくなると厳しいな。
男：三つ目はカフェ。時給は千二百円。週一日からOKで、場所は大学の隣。ただし、土日どっちかは必ず入ること。
女：土日か……。うーん、でも土曜なら大丈夫かな。時給は真ん中だけど、通うのが楽だし、週一からでいいっていうのがいいね。
男：僕なら、お金のことを考えて塾にするけどな。
女：私は勉強と両立できるほうがいいから、こっちにする。
```

**Question 1:** 女の学生はどのアルバイトを選びますか。

1. コンビニ
2. 塾
3. カフェ
4. まだ決めていない

**Answer:** 3

**Question 2:** 女の学生がそのアルバイトを選んだ一番の理由は何ですか。

1. 時給が一番高いから
2. 家から一番近いから
3. 深夜のシフトがないから
4. 勉強と両立しやすいから

**Answer:** 4

**Explanation:** コンビニは深夜×、塾は週三日必須×。カフェは時給は真ん中だが「通うのが楽」「週一からOK」、そして「勉強と両立できるほうがいい」が決め手。「家から近い」のはコンビニのほうで、カフェは「大学の隣」なので2は不正確。

### Script #19 — 展覧会の案内と相談
**Setting:** まず、美術館の案内を聞いてください。そのあと、夫婦が話しています。

```
案内：当美術館では、今月、三つの展覧会を開催しています。一階の「日本の風景画展」は、入場無料で、写真撮影もご自由にどうぞ。二階の「近代ヨーロッパ絵画展」は、入場料千五百円、写真撮影はご遠慮ください。毎週金曜日は夜八時まで開館しています。三階の「子ども向け体験アート」は、入場料五百円で、お子様が実際に絵を描いたり、作品に触れたりできます。こちらは事前予約が必要です。なお、二階と三階のチケットをセットでお買い上げいただくと、合計千七百円になります。

夫：どうする？子どもは三階に行きたがるだろうね。
妻：うん、でも三階は予約が要るって。今からじゃ無理かな。
夫：さっきスマホで見たら、今日の午後はまだ空いてたよ。
妻：じゃあ、それは予約しよう。私は二階も見たいな。
夫：セットだと三百円安くなるんだね。じゃあ、僕は子どもと三階に行くから、その間に二階を見てきなよ。
妻：ありがとう。写真は撮れないけど、ゆっくり見たい。一階は帰りにみんなで寄ろうか。
夫：うん、そうしよう。
```

**Question 1:** 妻はどの展覧会を一人で見ますか。

1. 一階の風景画展
2. 二階のヨーロッパ絵画展
3. 三階の体験アート
4. 二階と三階の両方

**Answer:** 2

**Question 2:** この家族は入場料を全部でいくら払いますか。

1. 五百円
2. 千五百円
3. 千七百円
4. 二千円

**Answer:** 3

**Explanation:** 妻は二階を一人で見て、夫と子どもは三階へ。一階は無料で帰りに全員で寄る。料金は二階（千五百円）＋三階（五百円）＝二千円だが、セットで買うと千七百円（夫が「セットだと三百円安くなる」と確認している）。一階は無料なので追加なし。

### Script #20 — 新しい社内制度
**Setting:** 会社で、三人が新しい制度について話しています。

```
課長：来月から、在宅勤務が週二日まで認められることになりました。申請は前の週の金曜日までに、システムから出してください。ただし、月曜日の朝は全員出社の会議があるので、月曜は在宅にできません。
男：質問いいですか。在宅の日に、お客さんとの打ち合わせが急に入った場合はどうなりますか。
課長：その場合は、出社に切り替えてもらいます。申請の変更はシステムで当日でもできます。
女：パソコンは会社のものを持ち帰るんですか。
課長：はい。家のパソコンは使えません。それから、在宅の日は、朝九時と夕方五時に、必ずチャットで報告を入れてください。
男：週二日というのは、連続でもいいんですか。火曜と水曜とか。
課長：連続でも構いません。ただ、チームの中で同じ日に全員が在宅にならないように、リーダーが調整します。
女：わかりました。私は火曜と木曜で出してみます。
男：僕は木曜と金曜にしようかな。
```

**Question 1:** 在宅勤務ができないのは何曜日ですか。

1. 月曜日
2. 火曜日
3. 金曜日
4. 土曜日

**Answer:** 1

**Question 2:** 在宅勤務について、正しいものはどれですか。

1. 家のパソコンを使ってもいい
2. 申請は当日でも変更できる
3. 週二日は連続ではいけない
4. 報告は夕方五時に一回だけすればいい

**Answer:** 2

**Explanation:** 月曜は全員出社の会議があるので在宅不可。家のパソコンは「使えません」（1×）。申請の変更は「当日でもできます」（2○）。連続は「構いません」（3×）。報告は朝九時と夕方五時の二回（4×）。

## After finishing all 20

- Score 16+ first-try: move to full-speed official 公式問題集 audio; treat these scripts as shadowing material only.
- Score 11–15: repeat the ones you missed after 3 days; identify whether your errors are *vocabulary* (word not known) or *processing* (word known but not caught). Processing errors are fixed by shadowing; vocabulary errors by Anki.
- Score 10 or below: go back to `listening-guide.md` and do two weeks of daily dictation on scripts #1–8 before attempting #9–20 again.

Common traps used in these scripts, which are the same traps used in the real JLPT:
- **やっぱり / それより / でも** — a change of decision after the first-mentioned option.
- **〜はいいです** — means "no thank you", not "is good".
- **〜てある / もう〜た** — something already done, so it is *not* the next action.
- **ただ / ただし** — introduces the one exception or the one complaint.
- A number said first is often the *old* number; the *final* number is confirmed by the other speaker ("〜だね", "〜ですね").
